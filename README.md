# 4320 / 7320 Plant Physiology — root teaching tools

Three self-contained browser tools used in the roots block. Each is a single HTML
file with no build step and no backend; the only external request is Google Fonts.

| file | what it is |
|---|---|
| `root-architect.html` | trait-allocation design tool with a transparent cost model |
| `calcium.html` | animated scenario simulator: calcium uptake and blossom-end rot |
| `recap.html` | interactive recap of the root anatomy lecture |

Served with GitHub Pages from the repository root.
